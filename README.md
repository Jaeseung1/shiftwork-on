# 교대온 — 교대근무표 시제품

모바일 화면에서 동작 흐름과 근무표 UI를 확인하기 위한 브라우저 시제품입니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 근무표는 현재 달력 날짜를 한국시간 기준으로 계산합니다. 날짜를 누르면 근무시간을 휴대폰/브라우저의 현지 시간대로 환산해 표시합니다.

- 반복 주기: 일 → 야 → 조 → 휴
- 일근: 한국시간 08:30–17:30
- 야근: 한국시간 17:30–24:00
- 조근: 한국시간 00:00–08:30 (야근 다음 날, 이어서 근무)
- 달력 날짜 및 주기 판정: 한국시간(Asia/Seoul)
- 표시 시간: 기기/브라우저 시간대에 맞춰 변환

## 파일

- `index.html` — 근무표 UI, 날짜별 수정, 설정 화면
- `control-center-concept.html` — iPhone 제어 센터 구성 시안
- `assets/control-center-preview.png` — 제어 센터 시안 이미지

## 시제품 한계

가족 초대 코드는 화면 시연용이며 서버 동기화가 되지 않습니다. iOS 제어 센터 컨트롤과 홈 화면 위젯도 실제 네이티브 기능이 아니라 시안입니다. 실제 iPhone 제어 센터는 WidgetKit Control을 추가해 구현해야 합니다.
