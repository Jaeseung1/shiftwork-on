아이폰 잠금 화면 위젯

잠금 화면에 오늘 근무가 늘 보여요. 무료 앱 Scriptable을 써요.

만드는 법 보기
  1. App Store에서 무료 앱 Scriptable을 받아요.
  2. 위 버튼으로 위젯 코드를 복사해요.
  3. Scriptable에서 +를 누르고 붙여 넣은 뒤, 위쪽 제목을 교대온으로 바꿔요.
  4. 잠금 화면을 길게 누르고 사용자화 → 잠금 화면 → 시계 아래 위젯 칸 → Scriptable에서 직사각형을 넣어요.
  5. 넣은 위젯을 누르고 Script에서 교대온을 골라요.

홈 화면에도 같은 방법으로 Scriptable 위젯(작은·중간)을 놓을 수 있어요. 아이폰이 새로 그리는 때를 정하므로 몇 분 늦게 바뀔 수 있어요. 코드에는 내 근무표를 읽는 열쇠가 들어 있어요.

아이폰 제어 센터 버튼

단축어를 만들면 제어 센터 버튼을 눌러 오늘·내일 근무를 알림으로 볼 수 있어요.

만드는 법 보기
  1. 위 버튼으로 주소를 복사해요.
  2. 단축어 앱에서 +를 누르고 URL 콘텐츠 가져오기를 넣은 뒤 주소를 붙여 넣어요.
  3. 사전 값 가져오기를 넣고 키에 today(오늘), tomorrow(내일), text(둘 다) 중 하나를 적어요.
  4. 알림 보기를 넣고 단축어 이름을 “오늘 근무”처럼 정해요.
  5. 제어 센터를 열고 왼쪽 위 + → 제어 항목 추가 → 단축어에서 방금 만든 단축어를 골라요.

주소에는 내 근무표를 읽는 열쇠가 들어 있어요. 믿는 사람에게만 알려 주세요. 오늘·내일을 따로 두려면 단축어를 두 개 만들면 돼요.
